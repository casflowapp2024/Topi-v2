Se requiere el id de la cuenta y las fechas del periodo y el tipo de cuenta.
Este es un ejemplo del body:
{"start":"2026-02-01","end":"2026-02-28","accounts_type":"savings","accounts":[19]}

4_Transacciones
Llama a esta herramienta cuando se requiera saber transacciones filtradas los siguientes parametros:
Descripción: query parameter "keyword". Ej: "keyword=didi"
gastos o ingresos: query parameter "expense", puede ser true or false. Ej: "expense=true"
cuenta: query parameter "account_id", tiene que ser un string de los ids separados por comas. Ej. "accounts=1,2,3"
periodo: query parameter "init_date" y "end_date", ambos en formato YYYY-MM-DD 00:00:00 -0500. Ej: "init_date=2022-01-01 00:00:00 -0500" "end_date=2022-01-01 00:00:00 -0500"
categoria: query parameter "categories", tiene que ser un string de los ids separados por comas. Ej. "categories=20,43"
un request con todos los query parameters se vería así
transactions/list?skip=0&limit=10&categories=20,43&accounts=25,44&init_date=2025-04-27%2000:00:00%20-0500&end_date=2026-02-25%2000:00:00%20-0500&keyword=d&expense=true
